# feishu-room-sniper

飞书会议室盯守抢订：满房的时段不用再一遍遍手动刷新。给定时段和截止时间，脚本持续监控目标会议室，**一有空房立刻以你的名义预订**，订到或到点自动停。

可以当命令行工具直接跑，也可以装成 Claude Code / lark-cli 的 Skill，对 Claude 说一句"3 点前帮我抢一间南楼的会议室"就行。

## 实测效果

真实环境连续两天验证：

> 16:42 开始盯守 17:00-18:00 南楼 → 16:44 某会议室被释放 → 16:44:45 预订 → 16:44:49 会议室回执 accept，全程 10 秒内。

## 依赖

- Python 3.8+（仅标准库）
- [lark-cli](https://www.npmjs.com/package/@larksuite/cli)：`npm install -g @larksuite/cli`
- 完成**用户身份**授权（日历域）：
  ```bash
  lark-cli auth login --domain calendar
  ```
  浏览器打开终端里的链接并确认。注意：飞书实际授予的 scope 可能比日历域多，介意的话可在飞书「设置 → 账号与安全 → 授权管理」收回。

## 直接命令行使用

```bash
# 盯今天 15:00-16:00 名字含"南楼"的会议室，截止 14:59:59，空了立马订
python3 scripts/room_sniper.py 2026-10-22T15:00:00+08:00 2026-10-22T16:00:00+08:00 --keyword 南楼

# 先看看现在有没有空房，不预订
python3 scripts/room_sniper.py 2026-10-22T15:00:00+08:00 2026-10-22T16:00:00+08:00 --keyword 南楼 --dry-run

# 自定义截止时间、标题、楼宇筛选
python3 scripts/room_sniper.py 2026-10-22T15:00:00+08:00 2026-10-22T16:00:00+08:00 \
    --keyword 南楼 --deadline 2026-10-22T14:30:00+08:00 --summary 需求评审 --floor F2
```

日志写在脚本同目录 `room_sniper.log`。

## 装成 Claude Code Skill

```bash
git clone https://github.com/Yida225/feishu-room-sniper.git ~/.claude/skills/feishu-room-sniper
```

之后对 Claude 说这些话就会触发（SKILL.md 里有完整定义）：

- "抢会议室" / "帮我占一个会议室"
- "盯着会议室，空了立马订"
- "到 3 点前帮我订到南楼的会议室"
- "15 点的会没房了，有空的就占上"

Claude 会先和你确认时段，查一轮空房，然后后台挂上盯守，订到或到点都会主动汇报。

## 参数说明

| 参数 | 说明 |
|------|------|
| `start` / `end` | 目标时段起止，ISO 8601 格式，必须带时区偏移（如 `+08:00`） |
| `--keyword` | 会议室名过滤关键词（如 `南楼`）。**推荐用它圈定范围**，各公司楼宇命名不统一，`--building` 经常筛不出结果 |
| `--deadline` | 盯守截止时间，默认时段开始前 1 秒 |
| `--summary` | 日程标题，默认"会议" |
| `--city` `--building` `--floor` | 透传给 lark-cli room-find 的位置筛选，仅在你明确知道命名时使用 |
| `--interval` | 轮询间隔秒数，最小 15（硬下限） |
| `--dry-run` | 只报告空房，不预订 |

## 行为细节

- **最小容量优先**：同时释放多间时先订容量最小的，不浪费大房间。
- **被拒不恋战**：会议室回执 declined 时自动删除刚建的日程，继续盯下一间。
- **审批中即停**：回执长时间未确认（可能要走审批）时保留日程并停止盯守，避免重复占房。
- **限流退避**：撞到飞书限流（code 190010）自动把下一轮等待拉长 3 倍，不会中断盯守。
- **结束必汇报**：订到（✅）或到截止时间没订到（❌）都会写日志并退出，退出码 0/1 区分。

## 使用须知

轮询间隔硬性下限 15 秒、一次只订一间，请勿用于囤占会议室；部分公司对会议室预订有管理规定，请遵守所在组织的要求。本工具全程以你本人的飞书身份操作，日程归属你自己，随时可在飞书日历中修改或删除。
